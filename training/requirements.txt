# Install (from training/):
#   uv venv --python 3.12 .venv
#   uv pip install -r requirements.txt

#   then regenerate the pin list below with `uv pip freeze`. Note
#   major-version upgrades in the plan-training.md changelog.
#
# Dependencies:
#   System: macOS + Xcode CLT, uv, Python 3.12 (see plan-training.md →
#           Prerequisites → System software).
#   License rule: permissive licenses only (MIT, Apache 2.0, BSD, ISC);
#           see agents.md → Dependency policy. Checked 2026-11-18: no GPL,
#           LGPL, or non-commercial licenses in the pinned set.
#
# Direct packages (everything else below is a transitive pin):
#   torch                 — training backend (MPS build)
#   transformers          — models, tokenizers, Trainer
#   datasets              — dataset building and caching
#   accelerate            — device handling for Trainer
#   conllu                — parsing UD .conllu files
#   seqeval               — CoNLL-style chunk precision/recall/F1
#   evaluate              — metric helpers
#   optimum, optimum-onnx — ONNX export (exporter lives in optimum-onnx) and
#                           quantization
#   onnx                  — ONNX model validation
#   onnxruntime           — ONNX inference for parity checks
#   numpy                 — numeric arrays
#   pandas                — reports and tables
#   pyyaml                — reading configs/*.yaml
#   sentencepiece         — DeBERTa-v3 tokenizer loading and fast conversion
#   protobuf              — required by sentencepiece tokenizer conversion
#   tensorboard           — local training logs (no external tracking service)
#   pytest                — tests for data conversion scripts
#   ruff                  — format and lint (dev only)
#
# Not included: unsloth — Phase 0 check failed on macOS (routes to MLX, not
#   PyTorch MPS) and its dependency unsloth-zoo is LGPL-3.0-or-later.
#
